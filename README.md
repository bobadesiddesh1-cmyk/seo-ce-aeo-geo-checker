# seo-ce-aeo-geo-checker

**GEO Lens — AEO/GEO Content Auditor** — a Manifest V3 Chrome extension that
scans any page for AI-search visibility issues (AI Overviews, ChatGPT,
Perplexity, Gemini) and highlights, in colour and on the page, exactly where the
content falls short for Answer Engine Optimization (AEO) and Generative Engine
Optimization (GEO). Everything runs locally in the browser.

The extension lives in [`geo-lens/`](./geo-lens). To install: open
`chrome://extensions`, enable Developer mode, click **Load unpacked**, and select
the `geo-lens/` folder. Full docs, rule explanations, and the Chrome Web Store
listing draft are in [`geo-lens/README.md`](./geo-lens/README.md); design
decisions are in [`geo-lens/DECISIONS.md`](./geo-lens/DECISIONS.md).
